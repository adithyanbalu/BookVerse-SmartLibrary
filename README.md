# 📚 BookVerse – Smart Digital Library

BookVerse is a Database Management System (DBMS) project designed to efficiently manage library operations through a structured relational database. The system maintains information about books, members, borrowing records, and library staff while ensuring data consistency and efficient retrieval. A simple and responsive web interface is provided for user interaction.

## Features
- Book Management
- Member Management
- Issue & Return Management
- Book Search
- Admin Dashboard

## Technologies Used
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Objective
To design and implement a relational database that automates library management by reducing manual work and improving data organization, retrieval, and integrity.
